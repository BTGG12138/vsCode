1.创建工作空间目录
创建母文件夹，复制.vscode，创建_ws文件夹

2.创建 ament_cmake C++ 包
ros2 pkg create --build-type ament_cmake cpp_demo --dependencies rclcpp

3.编译工作空间
cd ~/_ws
rm -rf build install log
colcon build --symlink-install --packages-select cpp_demo

4.source 环境，运行节点
source install/setup.bash
ros2 run cpp_demo Learning

5.查看自定义消息接口
. install/setup.bash
ros2 interface show cpp_demo/msg/Student

6.列出当前所有活跃话题，检查你的话题是否存在
ros2 topic list

7.ROS2 定义消息/服务/接口的包必备配置专门用于 .msg .srv .action 接口文件
<build_depend>rosidl_default_generators</build_depend>
<exec_depend>rosidl_default_runtime</exec_depend>
<member_of_group>rosidl_interface_packages</member_of_group>
